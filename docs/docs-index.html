DOCS

Index of every documentation file in this repository. If a doc isn't here, it doesn't exist yet.

How to use this index

If you're a user, start with README.md, then docs/install/. If you're a contributor, read CONTRIBUTING.md, then CLAUDE.md (yes, even if you're not Claude — it's the project's working manual). If you're an agent (Claude Code or otherwise), CLAUDE.md is mandatory. If you're evaluating the project's trustworthiness, read THREAT_MODEL.md, SECURITY.md, and GOVERNANCE.md.
